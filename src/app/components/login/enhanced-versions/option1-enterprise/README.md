# Option 1: Modern Split-Screen Enterprise Responsive Login Page

This folder contains the enhanced, fully responsive Enterprise Split-Screen Login Page for the LIMS Portal.

## Features Included:
1. **Fully Responsive Layout**: Mobile-first design that seamlessly scales from 320px mobile screens to 4K desktop screens without any horizontal overflow or height cutoffs.
2. **ISO 17025 & NABL Laboratory Branding**: Left-hand showcase panel with accreditation badges and core lab workflow highlights.
3. **Caps Lock Warning Indicator**: Real-time detection when Caps Lock is active during password entry.
4. **Remember Email Support**: LocalStorage persistence for user convenience.
5. **Modern Icon Input Groups**: Theme-compliant borders and focus rings with show/hide password toggle.

## How to Apply:
Copy the contents of:
- `login-option1.component.html` $\rightarrow$ `src/app/components/login/login.component.html`
- `login-option1.component.css` $\rightarrow$ `src/app/components/login/login.component.css`
- `login-option1.component.ts` $\rightarrow$ `src/app/components/login/login.component.ts`
